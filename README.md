# Anime Portfolio (アニメデータ収集・分析アプリ)

## 🌍 公開URL
https://anime-portfolio-vvbe.onrender.com/
> **Note:** 無料サーバー（Render）を使用しているため、一定時間アクセスがないとサーバーがスリープします。初回アクセス時は画面が表示されるまで約1分ほどかかる場合があります。

## 📝 アプリの概要
外部APIを利用して様々なアニメ作品のデータを収集し、ユーザーが閲覧・分析できるWebアプリケーションです。（※ここに「どんな画面で、何ができるのか」を1〜2行で追加します。例：気になった作品を検索し、独自のリストとして管理できます）

## 🛠 使用技術
* **バックエンド:** Python, Django
* **フロントエンド:** HTML, CSS, JavaScript (※使っていれば)
* **インフラ・デプロイ:** Render, SQLite (またはPostgreSQLなど)
* **外部連携:** ○○API (※使用しているアニメデータAPIの名前)

## ✨ 主要な機能
* **アニメデータの検索・取得:** 外部APIを叩き、「葬送のフリーレン」など特定の作品データや画像をリアルタイムに取得して画面に表示（※横スクロール等で工夫したUIがあればアピール）。
* **データ分析・管理:** 取得したデータをデータベースに保存し、一覧表示や分析が可能。
* **（予定）AIレコメンド機能:** 今後、ユーザーの好みに合わせたおすすめ作品を提示する機能を実装予定。
